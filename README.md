# BSIT 1-3 Section Portal

A simple section portal for BSIT 1-3 at Cavite State University – Main Campus.

Built with plain HTML, CSS, and vanilla JavaScript. No frameworks or build tools required.

## Features

- Class schedule by day
- Class code search
- Today's schedule
- Quick access links
- Course resources
- Section members
- Light and dark mode
- Responsive design for desktop and mobile

## Run Locally

Open `index.html` in your browser.

## Edit the Content

Most of the section data can be edited in:

`js/script.js`

This includes:

- `schedule` – classes, rooms, and times
- `quickLinks` – quick access cards
- `resources` – class resources
- `members` – section members
